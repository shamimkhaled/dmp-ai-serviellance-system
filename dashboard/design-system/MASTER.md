# VMS Intelligence — Design System

Dark OLED operations dashboard. Source: UI/UX Pro Max (`Dark Mode OLED` + Fira dashboard typography).

| Role | Hex |
|------|-----|
| Background | `#020617` |
| Surface | `#0F172A` |
| Panel | `#1E293B` |
| Primary / live | `#22C55E` |
| Accent / info | `#3B82F6` |
| Warning | `#F59E0B` |
| Critical | `#EF4444` |
| Text | `#F8FAFC` |
| Muted | `#94A3B8` |

- Headings/data: Fira Code. Body: Fira Sans.
- No emoji as UI icons. Icon-only buttons need `aria-label`.
- Hover: color/opacity 180ms, no layout-shifting scale.
- `prefers-reduced-motion` disables transitions.
- Product name: **VMS Intelligence**. Police GD/FIR is an Administration industry pack.
